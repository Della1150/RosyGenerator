# Rosy Prayer and Meme Generator

This is a beginner-friendly local web app for creating Rosy-style faith content:

- Short viral meme captions
- Longer prayers for Facebook comments
- Devotional paragraphs
- ChatGPT-ready image prompts for high-quality images
- Facebook/Pinterest hashtags

## How To Reopen The App

1. Open File Explorer.
2. Click `Desktop`.
3. Open the folder:

   ```text
   RosyPrayerGenerator
   ```

4. Double-click:

   ```text
   index.html
   ```

5. The app should open in your web browser.

If double-clicking does not work:

1. Right-click `index.html`.
2. Choose `Open with`.
3. Choose `Google Chrome`, `Microsoft Edge`, or another browser.

## How To Use The ChatGPT Image Prompt

1. Choose a `Topic`.
2. Choose a `Tone`.
3. Choose a `Brand`.
4. Choose a `Platform Size`.
5. Click `Generate`.
6. Find the `ChatGPT Image Prompt` section.
7. Click `Copy Prompt`.
8. Open your paid ChatGPT account.
9. Paste the prompt into ChatGPT.
10. Ask ChatGPT to create the image.

## How To Test The App

1. Click `Generate`.
2. Confirm these sections update:
   - Viral Meme Caption
   - Facebook Comment Prayer
   - Devotional Paragraph
   - ChatGPT Image Prompt
   - Hashtags
3. Click each `Copy` button and paste into a note, Facebook draft, or ChatGPT to make sure copying works.

## Current Features

- Rosy Minds-style header
- Soft pink, cream, lavender, and gold design
- Mobile-friendly layout
- Topic dropdown
- Tone dropdown
- Brand dropdown
- Platform size dropdown:
  - Facebook feed 1080x1350
  - Square 1080x1080
  - Reels 1080x1920
  - Pinterest 1000x1500
- Local placeholder caption, prayer, devotional, and hashtag generation
- Random caption selection by topic and tone
- Non-repeating captions during the same app session until the available variations are used
- Detailed ChatGPT-ready image prompt generation
- Brand-specific image instructions:
  - Rosy Minds creates Grace, an illustrated woman with a cross necklace
  - Rosy Revelation creates an expressive Holy Grandma character
  - Rosy Faith Chatter creates a discussion-style image with scenery, commentary, and a question
  - Rosy's Blank Canvas creates painted canvas-style artwork
- Seasonal and holiday-aware image prompt details
- Copy buttons beside every generated result

## Notes

- This version does not use a paid API.
- It works as a local browser app.
- No installation is required.
- For the best image quality, copy the generated prompt into your paid ChatGPT account.

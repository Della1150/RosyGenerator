# ROSY MINDS GARDEN

**A Daily Moment with Jesus**

This folder contains the finished first release of a free, installable, Jesus-centered web app for the Rosy Minds community.

## Features

- 30 original daily moments with Scripture references
- Hope, Peace, and Joy Promise Petals
- Short prayers and gentle grace steps
- Simple three-choice Bible questions
- A faith garden that grows with each completed day
- 30 collectible blessings
- Milestone rewards: butterflies at 7, a fountain at 14, a sparrow at 21, and a chapel at 30
- Device-only progress using local storage
- Direct link to the official Rosy Minds Facebook Page
- Offline support after the first successful visit
- No login, advertising, database, analytics, or paid API

## Public GitHub Pages path

When GitHub Pages is enabled for the `main` branch and repository root, the follower app is available at:

`https://della1150.github.io/RosyGenerator/rosy-minds-garden/`

Only this regular address should be shared. The public 30-day preview parameter has been disabled so every visitor sees only the progress saved on her own device.

## Privacy

The app does not request or collect names, email addresses, prayer requests, or other personal information. Progress is stored only in the follower's browser on that device.

## Updating

Keep the folder name `rosy-minds-garden` unchanged so existing shared links continue to work. Update the files in this folder and GitHub Pages will republish them.
